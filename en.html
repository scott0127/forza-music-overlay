Overview

How It Works

The overlay reads track information directly from the Windows System Media Transport Controls (SMTC) current media session. No logins required—play through official apps, and your credentials stay perfectly safe.

Floating Information

Displays the current song, cover art, playback status, progress, and source in-game.

Global Shortcuts

Full keyboard support for play/pause, skipping tracks, volume control, and hiding the overlay.

Controller Combos

Hold L3 (left stick) and press A / B / X / D-Pad Up / Down to control playback seamlessly.

Dual Themes

Supports Dark Mode and Liquid Glass aesthetics. Scale the widget size to your preference.

Quick Guide

Quick Guide

After launching, choose your music service. Once in Forza, use keyboard or gamepad controls without leaving the game.

60% - 100%

Adjust Overlay Size

Use the size slider in the main interface to scale the overlay between 60% and 100%.

Ctrl + Alt + P

Drag to Reposition

Press the reposition hotkey, drag the overlay to your preferred spot, then return to the game.

L3 + A

Play / Pause

Hold L3 (left stick press) and press A in-game to play or pause the current track.

L3 + B / L3 + X

Next / Previous Track

L3 + B skips to the next track, L3 + X goes back to the previous one — all without leaving Forza.

L3 + ↑ / ↓

Adjust Volume

L3 + Up to increase volume, L3 + Down to decrease volume.

Ctrl + Alt + Home

Show / Hide Overlay

Use this hotkey to quickly toggle the overlay on or off when you want a clean screen.

Install Flow

Installation Guide

After extracting, just run the exe directly. Only run Install-App.bat if you want desktop and Start Menu shortcuts.

STEP 1

Download ZIP

Download the latest ZIP archive from GitHub Releases.

STEP 2

Extract

Fully extract the folder — don't run the exe from inside the archive.

STEP 3

Run the EXE

Double-click ForzaMusicOverlay.exe to get started.

OPTION

Create Shortcuts

Run Install-App.bat if you need desktop shortcuts.
