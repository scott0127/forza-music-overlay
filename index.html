Overview

這個工具做什麼

程式透過 Windows 目前媒體工作階段讀取歌曲資訊。啟動後可從控制台開啟 YouTube Music、Spotify 或 Apple Music，選擇 App / System 音量控制、動態歌詞與三種懸浮播放器主題。登入都在官方服務中完成，工具本身不會要求、保存或讀取帳號密碼。

歌曲資訊與動態歌詞

在遊戲中顯示歌曲、縮圖、進度、服務來源，以及即時滾動歌詞。

App / System 音量切換

自由選擇只調整音樂 App，或同步調整 Windows 系統主音量。

手把組合鍵

支援 L3 (左蘑菇頭按壓) + A / B / X / 左 / 右控制播放、切歌與音量。

三種播放器主題

支援暗黑、Liquid Glass 與無邊框電台，並可調整播放器大小與位置。

Quick Guide

簡易操作教學

啟動後先選擇音樂服務，再設定音量控制目標與動態歌詞；進入 Forza 後就能用鍵盤或手把操作。

STEP 1 · MUSIC SOURCE

開啟音樂服務

先在控制台的「選擇音樂來源」區塊按下服務按鈕。程式會開啟對應官方網站，並自動替播放器套用符合服務的顏色主題。

APP / SYSTEM

選擇音量目標與歌詞

依照遊玩習慣選擇音量控制目標，也能決定是否在懸浮播放器顯示即時滾動歌詞。

  • App：只改變目前音樂網頁或應用程式的音量。
  • System：調整整台電腦的 Windows 系統主音量。
  • 動態歌詞可隨時開關，不需要重新啟動程式。

60% - 100%

調整懸浮大小

在控制台使用「懸浮播放器大小」滑桿調整比例，變更會立即套用並自動記住。畫面太擋或太小時都能細部微調。

Ctrl + Alt + P

拖曳調整位置

按下控制台的「調整懸浮位置」，或使用 Ctrl + Alt + P 進入定位模式。直接拖曳播放器，放到順眼的位置後再次按下即可保存。

L3 + A

播放 / 暫停

遊戲中按住 L3（左蘑菇頭按壓）再按 A，就能播放或暫停目前歌曲。使用鍵盤時則按 Ctrl + Alt + Space。

L3 + B / L3 + X

下一首 / 上一首

L3 + B 切到下一首，L3 + X 回到上一首，不需要離開 Forza。鍵盤可使用 Ctrl + Alt + 右 / 左方向鍵。

L3 + ← / →

調整音量

L3 + 右鍵調高音量，L3 + 左鍵調低音量；鍵盤則使用 Ctrl + Alt + 上 / 下。調整時會在遊戲畫面中顯示音量視覺提示。

Ctrl + Alt + Home

顯示 / 隱藏播放器

想暫時收起左上角懸浮播放器時，可以用 Ctrl + Alt + Home 快速切換。音樂仍會繼續播放。

Ctrl + Alt + H / Q

叫回控制台 / 退出

關閉控制台後程式仍會留在系統匣。按 Ctrl + Alt + H 叫回控制台，按 Ctrl + Alt + Q 才會完整退出程式。

Install Flow

安裝流程圖像說明

解壓後可直接點 exe 使用；需要桌面、開始功能表與「只顯示播放器」捷徑時，再執行 Install-App.bat。

STEP 1

下載 ZIP

從頁面上方的下載按鈕或 GitHub Releases 取得最新版 ZIP 壓縮檔。下載開始後，瀏覽器通常會將檔案放在預設下載資料夾。

STEP 2

解壓縮

對 ZIP 檔按右鍵並選擇全部解壓縮。請保留完整資料夾結構，不要只把 exe 單獨移出，也不要直接在壓縮檔內執行。

STEP 3

直接點 exe

雙擊 ForzaMusicOverlay.exe 即可開啟控制台。啟動後先挑選音樂服務，再依需求設定播放器大小、位置、音量目標與動態歌詞。

OPTION

建立捷徑

需要快速啟動時，再執行 Install-App.bat。它會建立桌面捷徑、開始功能表捷徑，以及略過控制台的「只顯示播放器」啟動入口。
