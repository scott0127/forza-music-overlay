Overview

這個工具做什麼

程式透過 Windows 目前媒體工作階段讀取歌曲資訊。登入 YouTube Music、Spotify 或 Apple Music 都在官方服務中完成，工具本身不會要求、保存或讀取帳號密碼。

播放資訊懸浮顯示

在遊戲中顯示目前歌曲、縮圖、播放狀態、進度與服務來源。

全域快捷鍵

支援播放、暫停、下一首、上一首、音量與顯示切換。

手把組合鍵

支援 L3 (左蘑菇頭按壓) + A / B / X / 上 / 下控制播放、切歌與音量。

雙主題介面

支援暗黑模式與 Liquid Glass，並可調整左上角懸浮播放器大小。

Quick Guide

簡易操作教學

啟動後先選擇音樂服務，進入 Forza 後可用鍵盤或手把控制，不需要切出遊戲。

60% - 100%

調整懸浮大小

在主介面的大小滑桿調整左上角懸浮播放器比例，畫面太擋或太小都能微調。

Ctrl + Alt + P

拖曳調整位置

按下調整懸浮位置後拖曳播放器，放到順眼的位置再回到遊戲。

L3 + A

播放 / 暫停

遊戲中按住 L3（左蘑菇頭按壓）再按 A，就能播放或暫停目前歌曲。

L3 + B / L3 + X

下一首 / 上一首

L3 + B 切到下一首，L3 + X 回到上一首，不需要離開 Forza。

L3 + ↑ / ↓

調整音量

L3 + 上鍵調高音量，L3 + 下鍵調低音量。

Ctrl + Alt + Home

顯示 / 隱藏播放器

想暫時收起左上角懸浮播放器時，可以用快捷鍵快速切換。
